##  Quick Reference

```
Search         → Grep/Glob (grepai si dispo)
Edit           → Read d'abord, Edit avec old_string exact
Server data    → TanStack Query (jamais useState pour data)
Data fetching  → Server Components (par défaut)
Type Safety    → Zod aux frontières (jamais any)
Formatting     → Oxfmt (oxc.rs) — jamais Prettier
Testing        → Behavior, pas implementation
Git            → Quality gates d'abord, puis commit
Performance    → Mesurer avant d'optimiser
```
