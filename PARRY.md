# PARRY - The Agentic Linter

**Version:** 0.3.0 | **CLI:** `parry` | **Architecture:** Simplified (no daemon)

## What Changed in v0.3.0

- ✅ **Simplified architecture**: 2 crates instead of 7
- ✅ **No daemon**: Instant startup, no background process
- ✅ **Single hook**: One file for Claude Code integration
- ❌ **Removed commands**: `parryd status`, `parryd run`, `parry install`

## Claude Code Integration

Parry integrates via a **single PostToolUse hook**:

- **Validates AFTER** Write/Edit operations
- **Auto-fixes** common issues
- **Logs** non-fixable problems

The hook is installed at: `~/.claude/hooks/parry-post-write.cjs`

## Commands

```bash
parry check [paths]      # Validate codebase
parry watch [paths]      # Watch and validate on changes
parry run <cmd> [args]   # Run command with file validation
parry init               # Initialize project config
parry config <subcmd>    # Manage configuration
```

### Examples

```bash
# Check entire project
parry check

# Check specific files
parry check src/components/Button.tsx

# Watch mode
parry watch src/

# Run dev server with validation
parry run npm run dev

# Auto-fix issues
parry check --fix

# Specific validators
parry check --validators tailwind,imports
```

## Configuration

### Project Config

Run `parry init` in your project to create `.parryrc.toml`:

```toml
[general]
strict = false

[tailwind]
enabled = true
safe_list = ["p-*", "m-*"]
block_list = ["bg-red-500"]

[imports]
enforce_alias = true
alias_map = { "@/" = "./src" }

[rust]
enabled = true
warn_unwrap = true
```

### Global Config (Optional)

`~/.config/parry/config.toml` for global settings.

## Environment Variables

```bash
PARRY_BIN           # Path to parry executable

PARRY_AUTO_FIX=1    # Auto-fix safe issues (default: true)
PARRY_DEBUG=1       # Debug logging
```
